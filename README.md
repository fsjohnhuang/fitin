# Fitin – A lightweight, type-safe toolkit designed to eliminate the pain of responsive adaptation for data visualization dashboards.

Built with TypeScript for full type safety, Fitin provides a flexible viewport customization system and first-class UI component libraries for both Vue 3 and React. Focus on your charts, not on screen fit issues.

## ✨ Features

- 📐 Smart Viewport Adaptation – Automatically scales and fits dashboards to any container or screen size.
- 🛡️ Type-Safe Core – Written entirely in TypeScript for robust IDE support and runtime reliability.
- 🎛️ Custom Viewport Controls – Fine-tune scaling behavior, alignment, and responsive breakpoints.
- ⚛️ Framework Ready – Official component libraries for Vue 3 and React (with hooks).
- 🪶 Zero overhead – Minimal runtime cost, optimized for performance-sensitive dashboards.
